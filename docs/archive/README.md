# Archive — old notes, kept for history only

These files were written between late 2025 and mid 2026, mostly as AI-chat summaries
while the project was being prototyped. **They are out of date and often contradict
the code** (for example, several say "Bcrypt" or "100% complete"). Don't use them as
a guide to how anything works today.

Kept because they record the original ideas — especially
`PROJECT_VISION_AND_RECOMMENDATIONS.md`, the first description of the business and
the website — and the path the authentication work took before it moved out into
a separate project.

What's current: the root `README.md`, `backend/README.md` and `frontend/README.md`.
